推荐路线 2 · 福田口岸重规划版

狮子山 + 九龙市区 · 经福田口岸进出

主线：深圳地铁到福田口岸 → 落马洲支线 → 港铁东铁线入市区 → 登狮子山 → 同口岸返程。 福田非 24 小时，必须卡点；午饭大陆自带干粮。回程备选：Plan B 皇岗（24 小时）、Plan C 深圳湾（旅检至 24:00）。

主口岸：福田 ↔ 落马洲支线 · 06:30–22:30 Plan B：皇岗 · 24h Plan C：深圳湾 · 至 24:00 核对：2026-09-29 UTC+8

01主线：为什么选福田

关门时间：福田口岸 / 落马洲支线管制站每日 06:30–22:30。 建议最迟 21:00–21:30 抵达落马洲管制站排队（周末黄昏更早）。 赶不上 → 立刻切 Plan B 皇岗（24 小时）或 Plan C 深圳湾（旅检至 24:00，见下方专节）。

福田口岸怎么走

深圳侧
福田口岸（深圳地铁 4 号线 / 10 号线 · 福田口岸站）
出闸后按指示办理内地出境 → 步行过桥约 5–10 分钟 → 香港落马洲支线管制站入境。
香港侧
办完入境后直达 港铁落马洲站（东铁线），入闸乘车进市区。
站内即可购票 / 拍八达通，无需再换乘跨境巴士。
付款
香港段：八达通最省事；亦可用车票二维码 / 感应卡。
深圳地铁：深圳通、支付宝 / 微信乘车码、现金购票等。
优惠
福田口岸站（深圳地铁 4 号线付费区）设有港铁特惠站：成人八达通 / JoyYou 卡拍机后， 即日经落马洲回港可减 HK$3（以港铁现行公告为准；有时亦有即日来回减 $6 推广）。

02标准 Timeline（福田口岸版）

08:20 – 09:20
福田口岸出境 → 落马洲支线入境 → 落马洲站
深圳地铁到福田口岸站，办内地出境，步行过桥，办香港入境。 平日非繁忙约 15–25 分钟；周末早上可能 40–60 分钟，请提早。 入落马洲站拍八达通上车。
09:20 – 10:10
东铁线 → 九龙塘 → 观塘线 → 黄大仙 / 乐富
落马洲开出约每 9–14 分钟一班。到九龙塘同层/站内转观塘线（往调景岭）， 下一站乐富，再下一站黄大仙。车程连转乘大约 35–50 分钟。
10:15 – 13:45
登狮子山（约 3–3.5 小时）
方案 A：黄大仙站 → 的士约 HK$30–40 上沙田坳道（法藏寺附近），或小巴 18M / 73 到慈云山道与沙田坳道交界再步行。
方案 B：乐富站步行经天马苑 → 狮子山公园登山口。
节点：法藏寺 / 沙田坳 → 麦理浩径第 5 段 → 回归亭一带 → 山顶 495 m → 狮尾 → 天马苑 / 黄大仙方向下山。 崖边无护栏，严禁探出拍照。
13:45 – 15:30
山顶 / 半山吃自带干粮 · 下山 · 黄大仙祠（可选）
午饭自大陆携带（三明治等干粮），在山顶平台或下山途中阴凉处食用；下山后只补水洗手。 可选逛黄大仙祠。不安排港式茶餐厅午餐，省下时间给市区或更早返程缓冲。
15:45 – 18:45
市区轻松段（时间比皇岗版更紧）
二选一：深水埗市集小吃，或旺角 / 尖沙咀星光大道看黄昏维港。 因口岸 22:30 关门，这段建议控制在 2.5 小时内，不要再开新大项。
18:50 – 20:10
回落马洲站（务必提早）
由黄大仙 / 旺角 / 尖沙咀经观塘线或东铁线北上落马洲。 旺角东亦可上东铁，但要确认班次是往落马洲而非罗湖。 车程约 40–55 分钟，再加步行出闸与过关。
20:10 – 21:30
香港出境 → 过桥 → 福田口岸入境
目标：最迟约 21:00–21:30 进入管制站流程。办香港出境 → 过桥 → 深圳入境。 若当日想用特惠：在深圳地铁福田口岸站付费区拍港铁特惠机后再出闸。 明显赶不上 → 立刻改走 Plan B 皇岗 或 Plan C 深圳湾（见第 03 节）。

03回程备选 · Plan B 皇岗 / Plan C 深圳湾

何时切备选：预计无法在 21:00–21:30 前进入落马洲支线管制站流程（延误、排队过长、东铁挤爆），就不要硬冲福田 22:30。 决策顺序：还能赶午夜前 → 可看 Plan C；已经很晚或想最稳 → 直接 Plan B。

Plan B · 皇岗口岸（最稳兜底）

通关
00:00–24:00（深圳唯一常态 24 小时旅检口岸）。重建新楼预计 2026 Q4 才正式开通，当前临时旅检仍 24 小时营运。
怎么走
从旺角鸦兰街（金都广场对开 / 近维景酒店）上旺角跨境全日通，经落马洲管制站到皇岗。
24 小时营运：日间约 15–20 分钟一班，深宵约 30 分钟一班。
车费
成人约 HK$45（06:01–23:30）；深宵 HK$50（23:31–06:00）。
八达通常有平日优惠（北行约 $43 / 南行约 $35，以车头告示为准）。
落地深圳
出联检楼过天桥 → 地铁 7 号线 · 皇岗口岸站回市区；亦可公交 / 的士。
适用
错过福田 22:30、凌晨仍在港、或市区已在旺角附近时优先。

Plan C · 深圳湾口岸

通关
旅检 06:30–24:00（到午夜，不是 24 小时）。过关道路会在停止运作前约 30 分钟封闭，务必更早抵达。
怎么走（推荐）
跨境直通巴：旺角朗豪坊 / 维景酒店一带、尖沙咀海港城 / 中港城等站上车，直达深圳湾（一地两检）。
班次与末班因公司而异，常见末班约 22:00–22:45；上车前用运营商 App / 现场问末班。
备选接驳
港铁屯马线到屯门站 → 城巴 B3X / B3 到深圳湾口岸（港方口岸区）。
屯门开出末班约 22:15–22:40 量级；口岸侧回程巴士可更晚，但对你「回深圳」帮助不大。
车费
直通巴约 HK$50–60；屯门接驳巴士约 HK$16.5 + 港铁到屯门。
落地深圳
出联检楼北侧 → 公交总站 / 出租车；需再转公交或网约回福田 / 南山（深圳湾无直达地铁）。
适用
赶不上福田但仍能在 23:00 前到口岸；人在尖沙咀 / 西九方向时比折返落马洲更顺。若已过直通巴末班且赶不上 B 线 → 改 Plan B。

06预算与行前准备清单

一人粗算（成人）

深圳地铁往返福田口岸约 ¥4–16
港铁落马洲 ↔ 黄大仙 ×2约 HK$84–86
的士 / 小巴上山约 HK$10–40
午餐（自带干粮）HK$0（大陆已备）
可选小吃 / 饮料约 HK$0–40
备选：皇岗全日通（Plan B）约 HK$45–50（替代福田回程港铁）
备选：深圳湾直通巴（Plan C）约 HK$50–60 + 深圳侧接驳
交通+可选小吃合计约 HK$100–180 + 少量人民币（走备选时再加）

另备少量港币现金应急（小巴 / 的士找零），约 HK$50–100 即可。

出发前 3–7 天（证件与支付）

  • 通行证 / 护照有效期够用，且未临近过期
  • 签注续签 / 有效签注：团队 L / 个人 G 等类型与剩余次数核对；过期或次数用尽先办好再出门
  • 确认当日可经福田口岸出入（非仅限罗湖等限制情形）
  • 准备或充值香港八达通（实体卡或八达通 App）；余额建议 ≥ HK$150
  • 手机开通香港流量：漫游日包 / 香港 eSIM / 港卡；提前测一下能否上网
  • 备用支付：微信 / 支付宝境外能力、少量港币现金
  • 把福田口岸通关时间 06:30–22:30、返程闹钟写进日历

前一晚打包 · 装备

  • 防滑运动鞋（石级多，勿穿皮鞋 / 新鞋）
  • 速干衣 + 薄外套（山顶风大）；帽子
  • 擦汗毛巾 / 速干小方巾 1–2 条
  • 垃圾袋若干（自带干粮包装、纸巾；山上有猴子，垃圾必须带走）
  • 防晒：防晒霜、墨镜；可选驱蚊
  • 饮水 ≥ 1.5–2 L（可装好再过关；勿带大量液体汤羹）
  • 自带干粮：三明治等密封包装；另备少量电解质粉 / 盐糖
  • 充电宝（满电）+ 充电线；手机贴膜完好防摔
  • 创可贴、创可贴止血贴、少量止痛药；个人常备药
  • 轻便双肩包（双手腾空爬山）；雨衣 / 折叠伞（看天气）

出门当日再确认

  • 证件放固定夹层，过关可随手取
  • 八达通能拍闸；深圳地铁乘车码可用
  • 离线地图：下载黄大仙 / 狮子山 / 福田口岸离线区
  • 存好应急：同伴电话、紧急联络；可选下载「香港天文台」看风雨
  • 设闹钟：18:45 结束闲逛；20:30 评估是否改 B/C；21:00 前落马洲排队
  • 手机收藏：旺角鸦兰街上车点地图、深圳湾直通巴站点（朗豪坊 / 海港城）
  • 看一眼口岸人流 / 天气；暴雨或 3 号风球以上改期
  • 干粮放外袋易取处，遇猴群勿当众拆大袋食品
  • 回程前再核对：垃圾已装袋、水量、证件与八达通还在
补充提醒：通行证签注务必在出发前办妥，口岸现场无法「顺便续签」。 八达通可在罗湖 / 福田附近便利店或港铁客务充值，但登山当天不建议把时间花在办卡上。 垃圾袋不是可选项——狮子山近年垃圾问题突出，也避免引来猴子抢食。

通关时间以福田 / 落马洲支线、皇岗、深圳湾官方公布为准；巴士末班与车费请出发前再核。
