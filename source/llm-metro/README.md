# LLM Metro · 大语言模型演进地铁图

一个纯静态的中文学习网站：把大语言模型从 1950 到 2025 的发展画成一张可探索的地铁图。

## 打开方式

- 直接双击 `index.html` 用浏览器打开即可，无需安装、无需联网（原始资料链接需要联网）。
- 或在当前目录执行 `python3 -m http.server 8781`，然后访问 <http://127.0.0.1:8781>。

## 内容结构

- **27 个历史站点**，分为 4 个时代（智能萌芽 / 深度学习前夜 / 大模型时代 / 生成式 AI 浪潮）与 3 条轨道（理论奠基 / 关键技术 / 规模与产品）。
- **5 条技术线路**（智能萌芽、架构演进、规模革命、对齐与产品、开放生态），颜色贯穿全站。
- 每个站点包含：日期、一句话定位、简介、关键突破、为什么重要、关键词与原始论文／官方公告链接。

## 功能

| 功能 | 说明 |
| --- | --- |
| 地铁图 | 点击站点查看详情，按 `← →` 切换上一站／下一站，`+ / -` 缩放，拖动平移 |
| 线路筛选 | 点击线路标签只看某条技术线路，其余站点淡化 |
| 历史时间线 | 按年份平铺全部 27 个节点，点击可回到地图对应站点 |
| 学习路线 | 三条由浅入深的路线（8 / 9 / 6 站），可一键开始并显示「第 N / M 站」 |
| 搜索 | 按模型名、技术、年份检索，`⌘/Ctrl + K` 或 `/` 聚焦 |
| 收藏与进度 | 探索过与收藏的站点存在浏览器 localStorage，刷新不丢失 |
| 深链接 | `index.html#station=transformer` 可直接打开某一站 |

快捷键：`⌘/Ctrl+K` 搜索、`← →` 切站、`Esc` 关闭详情、`+ -` 缩放、`0` 复位、`S` 收藏。

## 内容说明

- 早期节点（图灵测试、感知机、ELIZA 等）属于 LLM 的**技术前史**，并非现代意义上的大语言模型。
- 线路串联表达思想关联，**不代表严格的直接继承关系**。
- 站点精选至 2025 年 1 月，内容依据论文与官方公告整理，每站均附原始来源链接。
